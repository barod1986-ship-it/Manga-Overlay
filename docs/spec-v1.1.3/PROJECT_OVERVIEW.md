# نظرة المشروع

## 1. الرؤية

منصة WordPress لمكتبة مانجا ومانهوا وقصص مصورة. يختار القارئ عملاً ثم فصلاً ويشاهد الصور الأصلية. إذا كانت ترجمة عربية متاحة، تُعرض فوق الصور كطبقة مستقلة قابلة للإظهار والإخفاء دون تعديل الملف الأصلي.

الميزة المركزية هي **محرر تعريب بصري داخل المتصفح** يستخدمه أعضاء مخولون لإضافة النص العربي وتنسيقه داخل فقاعات الحوار، صناديق السرد، النص الحر والمؤثرات الصوتية مع الحفاظ على جمالية الصفحة.

## 2. تجربة المنتج

1. دخول المكتبة والبحث/الفلترة.
2. فتح العمل ثم الفصل.
3. القارئ يختار `webtoon` أو `paged` وفق إعداد العمل/تفضيله.
4. إن وُجدت ترجمة عربية فهي ظاهرة افتراضيًا، مع زر `إظهار/إخفاء الترجمة`.
5. العضو ذو الصلاحية يفتح `/edit/` للفصل.
6. يضيف/يحرر عناصر الترجمة فوق الصفحة الأصلية.
7. الحفظ تلقائي، وآخر حفظ ناجح يصبح ظاهرًا للقراء مباشرة إذا كان الفصل منشورًا.
8. اسم المساهم يظهر في قسم منفصل وملفه الشخصي، لا فوق الصورة.

## 3. الفئات

- **زائر:** قراءة المكتبة والفصول العامة.
- **عضو:** القراءة، حفظ التقدم، التبليغ، الملف الشخصي.
- **مترجم/محرر:** استخدام محرر الترجمة ونشر الحفظ المباشر.
- **مشرف:** معالجة البلاغات ومراجعة المحتوى.
- **مدير:** إدارة المحتوى والإعدادات والصلاحيات.

صلاحية رفع الأعمال/الفصول مستقلة ويمكن منحها لمستخدم بعينه.

## 4. حدود MVP

يشمل:

- مكتبة + بحث + فلاتر.
- صفحة عمل + فصول وحالاتها.
- قارئ `webtoon` و`paged` مع RTL/LTR قابل للضبط.
- طبقة ترجمة عربية قابلة للتبديل.
- محرر بصري للأنواع الأربعة.
- Desktop + Mobile editor.
- Autosave + element-level locking + optimistic concurrency.
- Presets شخصية/خاصة بالعمل/عامة.
- مساهمات وملفات شخصية وبلاغات.
- لوحة إدارة ورفع صور الفصول.

لا يشمل MVP:

- ترجمة آلية أو OCR.
- تحرير Vector حر أو استيراد SVG من المستخدم.
- تعاون لحظي عبر WebSocket.
- Version History للترجمات.
- Offline durable outbox.
- نظام نقاط/اقتصاد/مكافآت معقد.
- لغات ترجمة هدف متعددة في واجهة المنتج، رغم أن نموذج البيانات يدعم `target_lang`.

## 5. مبدأ الجمالية

المترجم لا يكتب نصًا فقط؛ بل ينسق عنصرًا بصريًا. لذلك المحرر يوفر أشكالًا، حدودًا، خلفية، دورانًا، طبقات، auto-fit، snapping، خطوطًا عربية، وPresets قابلة لإعادة الاستخدام.


- الفصول غير المنشورة لا تُكشف للعامة؛ يمكن للمحرر/مدير المحتوى المخول فتحها داخل وضع التحرير عبر نفس موارد API الخاصة بالفصل.
