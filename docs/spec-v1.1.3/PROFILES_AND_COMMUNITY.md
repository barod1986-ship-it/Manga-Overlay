# الملفات الشخصية والمجتمع

## 1. الملف العام `/u/{username}/`

يعرض:
- avatar.
- display name.
- username.
- bio.
- profile tag/rank بسيط.
- تاريخ الانضمام (إن تقرر عرضه).
- عدد الأعمال/الفصول/العناصر الفريدة التي ساهم فيها.
- آخر الأعمال/الفصول التي ساهم فيها.

## 2. بيانات الملف

تستخدم WordPress user fields/usermeta للحقول البسيطة:
- `description` للنبذة.
- `mol_profile_tag` للتاج النصي.
- avatar عبر نظام WordPress/حل مخصص لاحقًا.

لا ننشئ جدول ملف شخصي مستقل في MVP.

## 3. Badges

ليست نظام gamification كامل. يمكن للمدير لاحقًا تعيين badge IDs بسيطة في usermeta، لكن ليست شرطًا للإطلاق.

## 4. البلاغات

القارئ لا يحتاج صلاحية محرر للتبليغ. البلاغ يرتبط بأدق كيان معروف: element ثم page ثم chapter.

## 5. الخصوصية في واجهة المساهمين

لا تُعرض معلومات خاصة. فقط بيانات الملف العام والإحصاءات المشتقة من المساهمات الحالية.
