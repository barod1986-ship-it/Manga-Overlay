# نظام المساهمات

## 1. تعريف المساهمة

المساهمة ليست عملية حفظ. المساهمة هي أن يقوم مستخدم بإنشاء أو تعديل **عنصر ترجمة محدد**.

المفتاح الفريد:

```text
(element_id, user_id)
```

أول مرة يلمس المستخدم عنصرًا: INSERT. كل Autosave لاحق لنفس العنصر: UPDATE `last_contributed_at` فقط.

## 2. العدادات

في الفصل:
- `unique_elements_contributed`: COUNT(rows) لكل user/chapter.
- `created_elements`: SUM(created_element).

في الملف الشخصي:
- أعمال فريدة ساهم فيها.
- فصول فريدة.
- عناصر فريدة.
- عناصر أنشأها.

لا يوجد `number_of_saves` في UI.

## 3. attribution

`mol_elements.created_by` يحدد منشئ العنصر، و`updated_by` آخر محرر. جدول contributions يحدد كل الأشخاص الذين ساهموا في العنصر دون حفظ تاريخ نصوصهم.

## 4. عرض الفصل

قسم `المساهمون` خارج الصور:
- ترتيب افتراضي حسب عدد العناصر الفريدة تنازليًا.
- الاسم + avatar + العدد.
- رابط الملف.

## 5. الحذف

إذا حذف عنصر، تحذف attribution الخاصة به لأن العنصر لم يعد جزءًا من الترجمة الحالية. هذا متعمد؛ النظام ليس سجل تاريخ.
