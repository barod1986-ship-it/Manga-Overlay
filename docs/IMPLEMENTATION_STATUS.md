## اختيارات التنفيذ المحلية

- أطوال النمط المرئية (font/border/padding) تحوّل بالنسبة لعرض الصورة، بينما Y/H بالنسبة لارتفاعها. جميع الأبعاد تقاس من الصورة الفعلية دون حشو مساحة العمل.
- `sfx-display-1` مربوط مؤقتًا بخط Tajawal 900 في تجربة الأجهزة، لأن المواصفات لم تعين ملف الخط الزخرفي النهائي. لم يُعتمد نمط SFX إنتاجي.
- الصورة المرجعية رسم هندسي أصلي لاختبار التغطية والمواضع. لا يضيف التفعيل بيانات محتوى افتراضية؛ يحتوي موقع التجارب الآن فصل فحص مسودة بصور اصطناعية أنشئت خلال اختبار التثبيت.
- `OverlayDraft` مشتق من أنواع العقد لكنه يحمل مفتاح جلسة محليًا؛ لا IDs أو versions أو نسب مساهمات محفوظة مخترعة.
- أثناء الإيماءة تبقى البكسلات محلية؛ يرسل المحرر الهندسة عند نهاية التحويل. يظهر “تم الحفظ” بعد تأكيد الخادم فقط. تجربة PoC مستقلة وغير متصلة.
- السحب على العنصر المحدد يحوّله، واللمس على المساحة الفارغة يحرك الصفحة؛ الإصبع الثاني داخل مساحة الصفحة يستلم التكبير حتى فوق العنصر أو المقبض ويلغي التحويل المعلق. لا يستخدم pinch كبديل وحيد للدوران.

## استئناف 2026-09-06 — Core 0.4.0 / Theme 0.1.0

المواصفة المرفقة في الاستئناف طابقت الملفات الأربعين في المستودع byte-for-byte. بدأ الاستئناف من `440b290`، وليس من تاريخ T-13/T-15 في نسخة مستودع سابقة.

- آخر CI سابق توقف لأن مساعد الاختبار فرض array على DELETE 204 الفارغ. الإصلاح `76893e1` أوصل فحوص المحتوى إلى 162 ناجحة ثم كشف استخدام URL REST ثابت في اختبار HTTP؛ أصبح الاختبار يستخدم bootstrap WordPress الفعلي.
- WorkMutationLock ينسق إنشاء الفصل وحذف/نقل العمل للسلة عبر GET_LOCK على الاتصال، مع إعادة قراءة الأب بعد انتظار القفل وإطلاقه بعد اكتمال Core/shutdown. لا تعديل للجداول أو عقد المواصفة.
- قراءة القارئ العامة لا ترث صلاحيات المدير، ولا تظهر فصلًا منشورًا تحت عمل غير منشور.
- `/reading-progress` يستخدم عقده الأصلي؛ UPSERT منفصل لكل عضو/فصل، مع رفض موضع خارج الصفحات وموارد غير عامة. لا endpoint جديد لاستعادة التقدم؛ يضمَّن تقدم العضو الحالي فقط في HTML خاص غير قابل للتخزين المشترك.
- القارئ يضمّن overlay batch مرة واحدة، ولا ينشئ طلبًا لكل عنصر. الصور بأبعادها الصريحة والأولى eager؛ toggle يبقي عقد الصور، ويمسح ظهور الطبقة بأكملها.
- التكبير بأزرار حتى 300% مع overflow-pan، وpinch المتصفح متاح دون تعطيل تمرير اللمس. التحقق الفعلي من تجربة pinch داخل viewer على iOS/Android باقٍ.
- شاشة المحرر الإنتاجية والحفظ والأقفال على العناصر والـpresets والبلاغات لا تزال مهام لاحقة؛ لا تظهر أزرار موصولة بوظائف غير منفذة في القارئ.

ارتباط المتطلبات: FR-LIB-001/002/003/004، FR-WORK-001/002، متطلبات القارئ في READER_SPEC، FR-CMS-001 وFR-ADM-002؛ تحقق جزئي لـAC-01/02/03/10/11. لا ادعاء بإغلاق T-19 أو T-20.

اختبار الخادم الحقيقي والنشر إلى xCloud مؤجلان بطلب المستخدم. تبقى أجهزة الجوال الحقيقية وPHPCS/PHPStan وESLint/Prettier والأداء وسياسات cache النهائية بوابات مفتوحة. نتائج التشغيل المثبتة في `verification/RESULTS.md`؛ رأس المتابعة النهائي ونتيجته موثقان في PR #1. أضيف ترتيب رقمي للصفحات وإثبات UI لحفظه، واختبار UI لاستعادة تقدم العضو بعد reload.

## T-10 — Core 0.5.0 / Theme 0.1.1

- المسار الأصلي `/series/{slug}/chapter/{chapter}/edit/` يتحقق من جلسة WordPress و`mol_use_editor` قبل البحث عن المورد. الزائر يُحوَّل لتسجيل الدخول، والعضو دون الصلاحية يحصل على 403؛ المورد المفقود بعد التحقق يعطي 404.
- قالب المحرر وحزمته داخل الإضافة. HTML يحمل سياقًا صغيرًا وnonce للحساب الحالي دون payload الصفحات/العناصر؛ يقرأ React الفصل وصفحاته وعناصر الصفحة عبر عقود GET الأصلية. قراءة المسودات تبقى خلف سياسة REST، ولا تتغير دوال القراءة العامة.
- `#page=<id>&element=<id>` حالة تنقل في المتصفح، وليست route API جديدة. Back/Forward/reload يستعيد التحديد. تُلغى القراءة القديمة عند تغيير الصفحة، وتختفي طبقاتها فورًا أثناء التحميل.
- Stage يستخدم عرض/ارتفاع الصورة الحقيقيين والعارض DOM/SVG المشترك، مع zoom وoverflow-pan، وPreview يخفي التحديد واللوحات دون استبدال عقدة الصورة.
- قائمة الطبقات مرتبة للعرض فقط؛ IDs وversions والإسناد محفوظة في DTO الأصلية. لوحة الخصائص للقراءة، ولا يظهر مؤشر حفظ زائف أو أدوات تعديل غير موصولة. لا تُكتب بيانات الفصل في localStorage.
- أضيفت روابط من الإدارة والقارئ لمن لديه الصلاحية، ومعالجة empty/loading/404/network/expired-session. بيانات الاختبار تشمل صفحة طولية وأخرى عريضة ومسودة بأربعة أنواع عناصر.

يغطي ذلك FR-ED-001/010/012 وNFR-RTL-001، وجزءًا من FR-CH-002 وFR-ADM-003 وAC-02. ## T-11 — Core 0.6.0 / Theme 0.1.1

تحرير مؤقت متصل بصفحات WordPress الحقيقية. لكل صفحة نسخة عمل في ذاكرة React تحفظ المصدر وversion منفصلين عن تعديلات النص والنمط والهندسة. العناصر الجديدة والنسخ تحمل مفتاح جلسة فقط، بلا id/version/نسب مساهمة مخترعة. يبقى المصدر دون تعديل. لا طلبات كتابة ولا localStorage/IndexedDB لمسودات المحرر، ويظهر تنبيه قبل مغادرة جلسة تغيرت.

- إضافة الأنواع الأربعة، تحديدها، تحرير النص الآمن وخصائص الخط والخلفية والحدود والزوايا والحشو والظل. خيارات tail خاصة بالفقاعة، وخيارات burst/scale خاصة بـSFX.
- تحريك/تغيير حجم/دوران عبر Moveable؛ البكسلات محلية أثناء الحركة ثم تتحول إلى قيم normalized مقيدة بحدود العقد عند نهايتها. يلغي تغيير الصفحة أو إخفاء الطبقات أو تغيير أبعاد العرض التحويل المعلق.
- بدائل رقمية وأزرار خطوة لجميع التحويلات، وترتيب z-index، وDelete وCtrl/Cmd+D والأسهم وEsc خارج الحقول ومع استثناء تركيب النص IME.

## T-12/T-13/T-14 — Core 0.7.0

الحفظ الخادمي يستخدم المعاملات والجداول الأصلية دون تغيير schema 1.1.3. يطبق الخادم مخطط ElementCreate/ElementPatch وقيود النوع الثابت والهندسة؛ 2924 حالة مشتقة من المخطط تُقارن بمدقق JSON Schema مستقل في CI. الأنماط الأساسية مشتركة بين PHP وTypeScript، ويحل إنشاء العنصر أولوية preset الصريح ثم الشخصي والعمل والعام ثم الأساس، مع override أخير. إدارة presets لا تزال T-15.

كل عنصر له طابور حفظ مستقل ومفتاح POST ثابت مع payload ثابت عند غموض نتيجة الشبكة. الكتابة أثناء طلب جارٍ لا تُفقد. PATCH يبني If-Match من النسخة المؤكدة فقط. عند انقطاع PATCH يعاد فحص النسخة قبل إعادة المحاولة؛ لا overwrite صامت. المقارنة تعرض النص والهندسة والنمط وتتيح الحالية أو إعادة تطبيق الحقول المعدلة على الحالية. الأقفال لا تكشف token لمستخدم آخر، وتنتهي بعد 45 ثانية؛ تجدد الواجهة كل 15 ثانية أثناء التحديد/التعديل.

الحذف الخادمي يحتاج تأكيدًا للعنصر المحفوظ، مع تراجع قصير قبل إرسال الطلب. تزيل المعاملة العنصر والقفل والمساهمات وتفرغ مرجع البلاغ دون حذف البلاغ نفسه. الحفظ يحدّث مساهمة واحدة لكل عنصر ومستخدم؛ لا عداد لعدد الحفظات. الفشل في المساهمة يعيد المعاملة كاملة.

## T-15 — Core 0.8.0 / Theme 0.1.1

GET/POST/PATCH/DELETE للأنماط وفق المسارات والمخططات المجمدة. القراءة محصورة بالمحررين؛ الشخصي لصاحبه، وأنماط العمل ضمن work_id المحدد، والعام لكل المحررين. النشر والتعديل والحذف يحتاج الصلاحية الخاصة بالنطاق، وتُراجع عند كل طلب. الاسم نص آمن، والنمط يُفحص بحسب نوعه المخزن؛ لا content أو geometry داخل preset ولا تغيير لنوعه أو نطاقه عبر PATCH.

يُحسم الافتراضي الوحيد داخل transaction بعد قفل نطاقه، مع قفل استشاري يغطّي أيضًا النطاق الخالي دون تغيير الجداول. تنسّق أنماط العمل مع قفل حذف العمل وتنظف عند حذفه نهائيًا. حذف preset لا يعدّل أنماط العناصر التي طبّقته. فلاتر GET غير الصالحة تعيد قائمة فارغة ضمن عقد 200/401/403 المجمد.

شريط الأنماط أعلى الخصائص يتيح التطبيق والحفظ والتحديث والحذف وتعيين الافتراضي. التطبيق يغيّر style فقط، ويمسح مجموعات tail/shadow/burst القديمة صراحة عندما لا يتضمنها النمط الجديد؛ يتبع بعدها مسار autosave والأقفال نفسه. تظهر رسالة عند فشل العملية وتتطلب تحديث القائمة ومراجعة النتيجة قبل تكرار إنشاء preset؛ لا يفترض العقد idempotency لإنشاء الأنماط.

يستخدم المحرر أولوية الشخصي ثم العمل ثم العام ثم الأساس عند الإضافة. تنفذ Moveable محاذاة الحواف والمراكز للصفحة والعناصر الأخرى بعتبة خمسة بكسلات مرئية حتى بعد التكبير، مع toggle وAlt للتعطيل المؤقت. أزرار التوسيط بديل دون سحب. يقيس العارض المشترك النص بعد تحميل الخط، وإلغاء auto-fit يثبت الحجم المقاس؛ يظهر تنبيه عند استمرار التجاوز في الحد الأدنى. لا تتغير أبعاد العنصر بسبب الملاءمة.

## T-16 — Core 0.9.0 / Theme 0.1.1
