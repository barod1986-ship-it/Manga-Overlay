## متطلبات تدعمها التجربة دون ادعاء قبول الميزة كاملة

- FR-ED-002/003/004/005/006/007/008/009/010/012: نماذج الأنواع والتحويلات والعرض، ضمن الجلسة فقط.
- NFR-RTL-001 وNFR-A11Y-001: RTL وحقول وأزرار بديلة للسحب، مع مراجعة قابلية الاستخدام على الأجهزة باقية.
- AC-02: فقط ثبات الإحداثيات والمعاينة وإخفاء الترجمة في هذه الدفعة؛ لا يوجد قارئ عام أو سياسة مسودات حتى الآن.
- AC-03: أمان النص في العارض واختبارات المتصفح؛ لا يشمل validator الخادم أو اعتماد الخط على الأجهزة.
- AC-04/05/12: تجارب أولية فقط؛ لا تحفظ بعد reload ولا تُحتسب مكتملة.
- AC-CONTRACT-1: عقد المصدر ينجح في الفحص، وهذا ليس إثباتًا لتطبيقه في REST لم تُبنَ بعد.

## اختيارات التنفيذ المحلية

- أطوال النمط المرئية (font/border/padding) تحوّل بالنسبة لعرض الصورة، بينما Y/H بالنسبة لارتفاعها. جميع الأبعاد تقاس من الصورة الفعلية دون حشو مساحة العمل.
- `sfx-display-1` مربوط مؤقتًا بخط Tajawal 900 في تجربة الأجهزة، لأن المواصفات لم تعين ملف الخط الزخرفي النهائي. لم يُعتمد نمط SFX إنتاجي.
- الصورة المرجعية رسم هندسي أصلي لاختبار التغطية والمواضع. لا توجد أعمال أو فصول أو مساهمات وهمية في WordPress.
- `OverlayDraft` مشتق من أنواع العقد لكنه يحمل مفتاح جلسة محليًا؛ لا IDs أو versions أو نسب مساهمات محفوظة مخترعة.
- لا يصل أي pointer event إلى الشبكة؛ كل تحرير محلي. لا توجد حالة “saved” أو محاكاة لحفظ ناجح.
- السحب على العنصر يحوّله، واللمس على المساحة الفارغة يحرك الصفحة؛ إصبعان على المساحة الفارغة يكبران السطح. لا يستخدم pinch كبديل وحيد للدوران.

## بوابة الأجهزة — لا تُغلق بالمحاكاة

اختبر على iPhone/iPad حقيقي وAndroid حقيقي وسجل الطراز وإصدار النظام والمتصفح والنتيجة:

| السيناريو | iOS فعلي | Android فعلي |
|---|---|---|
| drag / resize / rotate قبل التكبير وبعده | معلق | معلق |
| pinch zoom وpan دون تعارض مع تحريك العنصر | معلق | معلق |
| textarea عربي، فتح/إغلاق لوحة المفاتيح واللوحة السفلية | معلق | معلق |
| النمط الأساسي، الأنواع الأربعة، معاينة النتيجة | معلق | معلق |
| وصلات الحروف العربية مع SFX stroke | معلق | معلق |
| تطبيق preset محفوظ، autosave، lock conflict | يتطلب T-12/T-13/T-15 | يتطلب T-12/T-13/T-15 |

مواصفات الجوال تطلب التحقق قبل بناء المحرر كاملًا. لا توجد نتيجة أجهزة مخمنة، ولا يُستبدل Moveable أو نموذج البيانات بناءً على المحاكاة وحدها.

## GitHub والنشر

حدد المستخدم المستودع `barod1986-ship-it/Manga-Overlay`، وتأكدت صلاحية الكتابة. كان المستودع فارغًا؛ تمت تهيئة `main` بملف تعريف، وتُرفع دفعة البداية على `codex/initial-renderer-editor` للمراجعة. نتائج التشغيل على GitHub موثقة في `verification/RESULTS.md` وسجل Actions.

لم يتم الدخول إلى xCloud أو الخادم. ملف GitHub Actions يشغل فحوص الواجهة، وأضيفت مصفوفة MySQL 8.4 وMariaDB 10.11 عبر WordPress 7.1/PHP 8.4 و`dbDelta()` الفعلية. نتائجها تُسجل بعد اكتمال التشغيل؛ لا توجد اختبارات نشر على NGINX الفعلي.
